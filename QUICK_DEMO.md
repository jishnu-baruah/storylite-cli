# ⚡ Quick Demo Guide - StoryLite CLI

> **5-minute demo that makes StoryLite look amazing**

## 🎯 Demo Goal
Show how StoryLite transforms the painful process of IP minting into something as simple as copying a file.

## 🎬 Step-by-Step Demo (Copy & Paste Ready)

### Setup (30 seconds)
```bash
# 1. Show the tool exists and works
storylite --help

# 2. Show current config (probably empty)
storylite config show
```
**Say:** *"This is StoryLite CLI - it makes IP protection as simple as copying a file."*

### One-Time Configuration (60 seconds)
```bash
# 3. Set endpoint (one time only)
storylite config set-endpoint https://universal-minting-engine.vercel.app

# 4. Set wallet address (one time only) 
storylite config set-address 0x742d35Cc6634C0532925a3b8D404d3aABb8c4532

# 5. Show beautiful config
storylite config show
```
**Say:** *"Two commands for setup. Set your endpoint and wallet address once, then never type them again."*

### Create Demo Files (30 seconds)
```bash
# 6. Create some files to mint
echo "console.log('Hello IP World!');" > demo-code.js
echo "# My Revolutionary Algorithm" > algorithm.md
echo '{"name": "My API", "version": "2.0"}' > api-spec.json
```
**Say:** *"Let's create some files to protect - code, documentation, and API specs."*

### The Magic - Effortless Minting (2 minutes)
```bash
# 7. Mint JavaScript code (no address needed!)
storylite mint demo-code.js

# 8. Mint with custom title
storylite mint algorithm.md --title "Revolutionary Algorithm Docs"

# 9. Mint with full metadata
storylite mint api-spec.json --title "API Specification v2.0" --description "Complete API documentation"

# 10. Show verbose mode for transparency
storylite mint demo-code.js --verbose
```
**Say:** *"Look at this! Any file, one command, instant IP protection. No addresses, no complexity."*

### Advanced Features (60 seconds)
```bash
# 11. Override address for specific case
storylite mint algorithm.md --address 0x9876543210987654321098765432109876543210

# 12. Show help system
storylite mint --help
```
**Say:** *"Need a different address for a client project? Override it. Want help? It's built right in."*

### Wrap Up (30 seconds)
```bash
# 13. Show config one more time
storylite config show

# 14. Show all available commands
storylite --help
```
**Say:** *"That's it! Install once, configure once, then protect any file with one simple command."*

## 🎨 Visual Tips for Great Demo

### Terminal Setup
- **Font**: JetBrains Mono or Fira Code, 14-16pt
- **Theme**: Dark background, light text
- **Colors**: Ensure green ✓, blue ℹ, red ✗ are vibrant
- **Size**: Large enough to read in video

### What to Highlight
- ✅ **Green checkmarks** - success is obvious
- 💡 **Helpful tips** - user-friendly design  
- 📋 **IP Asset IDs** - proof it worked
- 🔗 **Transaction hashes** - blockchain integration
- **Masked addresses** - security and privacy

### Timing
- **Type at normal speed** (not too fast)
- **Pause 2-3 seconds** after each output
- **Let viewers read** the success messages
- **Point with cursor** to highlight key info

## 🚀 Pro Tips

### Before Recording
1. **Practice 2-3 times** with the script
2. **Test all commands** to ensure they work
3. **Clear terminal history**: `cls` (Windows) or `clear` (Mac/Linux)
4. **Set up good lighting** and audio

### During Recording
1. **Speak with enthusiasm** - show you love the tool
2. **Don't rush** - let the beauty of the output show
3. **Emphasize the key benefit**: "No more typing addresses!"
4. **Show confidence** in every command

### Key Messages to Emphasize

- 🚀 **"Perfect for developers"** - built for workflows
